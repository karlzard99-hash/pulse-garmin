# Pulse — a private Garmin dashboard, set up by Claude

Pulls your own Garmin data onto your laptop each morning, shows it on a private claude.ai link,
writes your training week and sends it to your watch once you approve it in the chat.
Your data and login stay on your laptop; this repo holds only code.

To set it up, paste the prompt you were sent into the Claude desktop app's Code tab.
Claude follows `SETUP.md`.
